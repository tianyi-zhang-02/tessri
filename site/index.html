Get started from a source checkout for the unreleased review command.

An offline HTML brief, a pull request comment, or an agent's tools. Start with the question you need answered.

  • tessri review --since mainA local source and evidence workbench, with refresh and a visible stale-snapshot state.
  • tessri review --since main --out /tmp/review.htmlOne offline source snapshot to hand over from Codex, Claude Code, Copilot or another CLI.
  • tessri integration install --agent reviewA Markdown brief on each pull request, updated in place.

Static analysis cannot see runtime wiring or consumers outside the repository. Missing evidence stays unavailable; candidate tests stay separate from recorded results. The limits.
